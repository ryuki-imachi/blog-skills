# 良い例・悪い例

## 導入文

### ❌ 悪い例
> Reactでフォームを作ります。

問題点：何を解決するか不明、対象読者が分からない

### ✅ 良い例
> Reactでフォームを作る際、バリデーションの実装に悩んだことはありませんか？
> この記事では、React Hook Formを使って5分でバリデーション付きフォームを作る方法を紹介します。
>
> **対象読者**：React基礎を学んだ初心者〜中級者
>
> **前提条件**：
> - Node.js 18以上
> - React 18以上

---

## コードブロック

### ❌ 悪い例
```
npm install react-hook-form
```

問題点：言語指定がない、代替手段がない

### ✅ 良い例
```bash
# npmの場合
npm install react-hook-form

# yarnの場合
yarn add react-hook-form
```

---

## 長いコードの扱い

### ❌ 悪い例
100行以上のコードをそのまま貼り付け

### ✅ 良い例
```markdown
<details>
<summary>完全なソースコード（クリックで展開）</summary>

ここに長いコード

</details>
```

## 専門用語の説明

### ❌ 悪い例
> SSRを使ってSEO対策をします。

### ✅ 良い例
> SSR（Server Side Rendering：サーバーサイドレンダリング）を使ってSEO対策をします。
> SSRとは、サーバー側でHTMLを生成してからブラウザに送る仕組みです。

## 表記揺れ

### ❌ 悪い例
> ReactとJavaScriptでアプリを作成できます。
> Reactとjavascriptでアプリを作成出来ます。
> 全てのコードをGithubに上げて下さい。

問題点：
- `JavaScript` と `javascript` が混在
- 「できます」と「出来ます」が混在
- `GitHub` が `Github` になっている
- 「ください」が「下さい」になっている

### ✅ 良い例
> ReactとJavaScriptでアプリを作成できます。
> すべてのコードをGitHubにアップロードしてください。
